# Mora Icon System

产品图标从 Mora 字标中的偏心 `o` 与右上绿色知识节点派生。图标和 IP 共用识别结构，但图标不使用眼睛、四肢或场景道具。

## 文件

| 文件 | 用途 |
|---|---|
| `mora-icon-master.svg` | 主应用图标源文件，`1024 × 1024` |
| `mora-icon-mark.svg` | 透明背景双色标记，用于头像、启动页和开放版式 |
| `mora-icon-monochrome.svg` | 单色遮罩、雕刻、印刷和受限色环境 |
| `mora-favicon.svg` | `16–32px` 光学校正版 |
| `mora-icon-preview.svg` | 体系总览与尺寸检查板 |

## 使用规则

- 主体使用 `#202523`，活跃节点使用 `#12A77C`，浅色底使用 `#F3F6F4`。
- 深色背景时主体改用 `#F3F6F4`，内孔必须透出背景色。
- 不改变偏心轮廓、节点位置或节点的 45° 旋转角度。
- `20px` 及以上使用主标记；低于 `20px` 使用 `mora-favicon.svg`。
- 平台要求圆角或圆形蒙版时交给系统裁切，不额外改变标记比例。
- 不添加文字、描边、渐变、阴影、发光或额外品牌色。
