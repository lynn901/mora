# Mora IP：O

Mora 的正式 IP 来自字标中的小写 `o`。它是一个完整、略微偏心的墨色椭圆环，右上方佩戴唯一的绿色知识节点。角色与 Logo 共用同一识别结构，但 Logo 不使用眼睛和四肢。

## 角色设定

- 完整的偏心 O 是角色身体，不使用开口、嘴、眉毛或服装。
- 中央内孔小于标准圆环，让身体稳定、厚重，不像甜甜圈。
- 两只白点眼靠近内环上缘，保持冷静、专注和轻微荒诞感。
- 绿色节点固定在一点半方向，与身体轻微重合，不使用手、帽檐或连接线。
- 手臂仅在场景确实需要操作物品时出现；静止母版只保留短腿。

## Logo 联动

- 字标 `o` 使用同源的偏心轮廓，并在右上佩戴缩小的绿色节点。
- 完整 Logo 保留网络右下角的绿色节点，并在 `o` 上重复同源节点帽；两处绿色共同表达活跃知识。
- 字标节点约为 `o` 外径的 20%；IP 节点约为角色外径的 22%。
- 节点保持 Logo 原有的 45° 旋转，不做左右随机变化。

## 使用规则

1. 主体使用 `#202523`，节点使用 `#12A77C`，结构线使用 `#252A28`。
2. 不添加渐变、阴影、发光、纸张纹理或额外装饰色。
3. 不把节点画成被角色抓住的帽子；节点直接落在身体轮廓上。
4. 不改变内孔形状来模拟嘴或夸张表情。
5. 插画继续采用纯白背景、黑色手绘线稿和大量留白，每张只表达一个场景隐喻。

## 正式文件

- `mora-ip-master.svg`：透明背景 IP 母版。
- `../brand/mora-primary-lockup.svg`：包含同源 `o` 与节点帽的完整品牌母版。
- `01-retrieve-from-archive.svg`：从档案柜中唤回相关知识。
- `02-connect-at-switchboard.svg`：在旧式交换台前建立知识连接。
- `03-organize-with-press.svg`：用装订压机整理和沉淀散页。
- `04-page-not-found.svg`：把 O 形身体套在 404 机器吐出的过长空白纸带上，认真向外拉取不存在的页面。

## 场景规则

- 角色必须操作场景中的关键物品，移除角色后核心工作不能继续发生。
- 每张图只表达一个隐喻，不添加标题、动作名称或大段说明文字。
- 绿色只出现在角色的节点帽上；场景物品使用墨色线稿和中性灰结构线。
- 三张正式插画均使用 `1600 × 900`、纯白背景和不少于 35% 的留白。
