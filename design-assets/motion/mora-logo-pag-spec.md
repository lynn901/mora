# Mora Logo PAG 动效规格

## 交付目标

- 画布：`1024 × 1024 px`
- 帧率：`30 fps`
- 总时长：`54f / 1.8s`
- 背景：透明
- 播放：单次，不循环
- 色彩：主体 `#202523`，结构线 `#252A28`，活跃节点 `#12A77C`
- 输出：PAG Exporter 导出矢量 `.pag`，关闭位图预合成

## 图层顺序

| 层级 | AE / PAG 图层名 | 类型 | 说明 |
|---|---|---|---|
| 06 | `wordmark_active_node` | Shape | `o` 右上绿色节点 |
| 05 | `wordmark` | Shape | `m / o / r / a` 分字母路径 |
| 04 | `node_active` | Shape | 网络右下绿色节点 |
| 03 | `node_top` | Shape | 网络顶部墨色节点 |
| 02 | `node_left` | Shape | 网络左下墨色节点 |
| 01 | `network_line` | Shape | 三角知识连接线 |

所有节点锚点放在各自几何中心。菱形保留源 Logo 的 `45°` 旋转，不在动画中继续旋转。

## 时间轴

| 帧 | 时间 | 动作 | PAG 实现 |
|---|---:|---|---|
| `0–5f` | `0–0.17s` | 空场 | 全部图层不可见 |
| `6–19f` | `0.20–0.63s` | 知识网络连线生成 | Shape Trim Paths：`End 0% → 100%` |
| `8–17f` | `0.27–0.57s` | 左、上墨色节点依次出现 | Scale `72% → 100%`，Opacity `0 → 100%` |
| `13–22f` | `0.43–0.73s` | 右下绿色节点激活 | Scale `72% → 100%`，Opacity `0 → 100%` |
| `15–35f` | `0.50–1.17s` | 字标从左到右写入 | 每个字母 Trim Paths，间隔 `2f` |
| `31–40f` | `1.03–1.33s` | `o` 上绿色节点激活 | Scale `65% → 100%`，Opacity `0 → 100%` |
| `41–53f` | `1.37–1.77s` | 完整 Logo 静止 | 不增加呼吸、发光或循环动作 |

## 缓动

- 线条绘制：`cubic-bezier(0.4, 0, 0.2, 1)`
- 节点出现：`cubic-bezier(0.2, 0.75, 0.25, 1)`
- 不使用弹跳、回弹、旋转入场或运动模糊
- AE 中使用 Easy Ease 后，将速度曲线调整为单调收敛，不允许超过 `100%` Scale

## PAG 兼容约束

1. 仅使用 Shape Layer、Trim Paths、Opacity、Scale 和基础路径。
2. 不使用表达式、3D 图层、蒙版羽化、渐变、阴影、发光或混合模式。
3. 字标必须转换为路径，禁止依赖运行时字体。
4. 导出前确认所有图层在 `54f` 内结束，Work Area 与合成长度一致。
5. PAG Exporter 中保留矢量内容，目标端按单次播放并停在末帧。
6. 无障碍降级直接展示 `design-assets/brand/mora-primary-lockup.svg` 静态 Logo。

## 验收点

- 第 `0f` 完全透明，第 `53f` 与 `mora-primary-lockup.svg` 视觉一致。
- 两个绿色节点只在规定位置出现，颜色无漂移。
- 知识网络早于字标建立，因果顺序清晰。
- 1×、2×、3× 渲染下线条端点无裁切，透明边缘无黑边。
- Android、iOS、Web PAG 播放器各播放一次后停在末帧。
